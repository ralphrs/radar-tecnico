# Roadmap navegável

`index.html` é o roadmap do Lookout em uma página só (trilho por tema, decisões, diagramas). Não edite o HTML: mude as fontes e gere de novo.

- `pages1.cjs` e `pages2.cjs`: o texto das 18 páginas.
- `diagrams.cjs`: os diagramas de fluxo em SVG (colunas fixas, caixas numeradas).
- `css.cjs`, `svg.cjs`, `ui.cjs`: estilo e componentes.
- Gerar: `node gen.cjs index.html`.

A mesma página vai para o second brain (`gerencia-de-projetos/pessoais/roadmap-lookout.html`) e para o artifact no Claude. O ROADMAP.md da raiz continua sendo a lista de referência; esta página é a versão para ler e navegar.
